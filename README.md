# Employee Payroll Management System

## About the Project
Employee Payroll Management System is a Java-based console application developed using Object-Oriented Programming (OOP) concepts. It helps manage full-time and part-time employees and calculate their salaries.

## Features
- Add Full-Time Employees
- Add Part-Time Employees
- View All Employees
- Search Employees using Employee ID
- Calculate Full-Time Employee Salary
- Calculate Part-Time Employee Salary

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Inheritance
- Polymorphism
- Encapsulation
- ArrayList
- Scanner
- Eclipse IDE

## Project Structure
- `Employee.java` – Base class containing common employee details.
- `FullTimeEmployee.java` – Manages full-time employee salary details.
- `PartTimeEmployee.java` – Calculates salary based on hours worked and hourly rate.
- `PayrollApp.java` – Main class containing the payroll management menu.

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse IDE.
3. Run `PayrollApp.java` as a Java Application.
4. Select an option from the menu.
5. Enter the required employee details.
